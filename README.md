# Chenxu Zhang · Academic Homepage

Personal academic homepage: https://tasselszcx.github.io/

A responsive static site with biography, selected publications, education, research experience, and open-source contributions.

## Editing

- `index.html`: profile, biography, education, and experience.
- `site.js`: publication entries, author order, links, and citations.
- `style.css`: layout and responsive styles.
- `assets/`: profile image and paper figures.

Preview locally with `python3 -m http.server 8765` and open http://127.0.0.1:8765.

GitHub Pages publishes the root of the `main` branch. No build step is required.

Layout inspired by https://rosy0912.github.io/. Paper figures are credited through links to their original papers. The SkillLens thumbnail is an explicitly labeled method summary.
